# Collaboration Guide

## Agent coordination

1. Read `STATE.md`, `PLAN.md`, and recent local logs when available.
2. Pick unclaimed work from `PLAN.md`.
3. Use the branching strategy in `BRANCHING.md` when Git is initialized.
4. Log meaningful events while working.
5. Close managed sessions so verification receives a summary.
6. Version durable control-plane files; regenerate local logs, quality output, and temporary evidence per environment.

## Human-agent split

Humans set direction and approve consequential product decisions. Agents implement, verify, record decisions, and report outcomes.
