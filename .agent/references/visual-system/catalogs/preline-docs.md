## Videotelemetry priority pages

- sidebar/navbar/offcanvas for the shell;
- cards/list groups/tables/datatables for operational data;
- timeline/tree/stepper for event and audit flows;
- charts/datamaps/maps for fleet and telemetry;
- modal/popover/dropdown/tooltip for contextual operations;
- skeleton/spinner/progress/toast for async workflows;
- accessibility, dark mode, themes and colors for the shared foundation.

Exact public package source, themes and official agent-skill documentation are preserved in `vendor/preline/`. Preline Pro and paid templates/blocks are intentionally excluded.
